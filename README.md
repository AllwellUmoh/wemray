# Wemray Technology Website

Next.js 16 App Router website for Wemray Technology, including the public
marketing site, contact enquiries, and a passwordless admin area.

## Stack

- Next.js 16 (App Router, Turbopack)
- React 19
- PostgreSQL (`pg`)
- Better Auth magic-link authentication
- Resend transactional email
- Zod validation

## Routes

- `/`, `/about`, `/services`, `/services/[slug]`, `/portfolio`, `/academy`,
  `/contact`, `/privacy`, `/terms`
- `/academy/courses/[slug]` — course detail, modules and enrolment form
- `/academy/enrol/success` — payment status
- `/academy/enrol/balance` — second-instalment checkout
- `/admin` — protected enquiries dashboard
- `/admin/enrolments`, `/admin/courses` — academy admin views
- `/admin/login` — magic-link sign in
- `/api/contact` — contact form endpoint
- `/api/academy/enrolments/initialize|verify|complete|status` — enrolment payments
- `/api/academy/coupon` — coupon validation
- `/api/academy/webhooks/paystack` — Paystack webhook (source of truth)
- `/api/auth/[...all]` — Better Auth handler
- `sitemap.xml`, `robots.txt`, `manifest.webmanifest` are generated by Next.js

## Getting started

1. Copy the environment template and fill in the values:

   ```bash
   cp .env.example .env.local
   ```

   Required production values: `DATABASE_URL`, `BETTER_AUTH_SECRET`,
   `ADMIN_EMAIL`, `RESEND_API_KEY`, `RESEND_FROM_EMAIL`,
   `CONTACT_NOTIFICATION_EMAIL`, `CONTACT_IP_SALT`, `NEXT_PUBLIC_SITE_URL`,
   `CONTACT_ENCRYPTION_KEY`, `PAYSTACK_SECRET_KEY`.

   Academy payments also read optional `PAYSTACK_CALLBACK_URL` and
   `ACADEMY_INSTALMENT_DAYS` (default 30). See `docs/RAY_ACADEMY.md`.

   The app reads the plain `DATABASE_URL` name. Neon/Vercel integration
   variables that are prefixed (for example `wemray_DATABASE_URL`) are not
   used, so make sure a `DATABASE_URL` value exists for the deployed
   environment.

2. Install dependencies:

   ```bash
   npm install
   ```

3. Create the database tables:

   ```bash
   psql "$DATABASE_URL" -f db/contact.sql
   psql "$DATABASE_URL" -f db/auth.sql
   psql "$DATABASE_URL" -f db/seo-analyzer.sql
   psql "$DATABASE_URL" -f db/academy.sql
   psql "$DATABASE_URL" -f db/academy.seed.sql
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

## Security

- Strict security headers (CSP, HSTS, `X-Frame-Options: DENY`, COOP/CORP,
  Permissions Policy) are configured in `next.config.mjs`.
- Admin routes are protected in `src/proxy.ts` and re-checked server-side with
  `requireAdmin()`.
- Admin sign-in is passwordless: only `ADMIN_EMAIL` is allowed, magic links
  expire after 10 minutes, and requests are rate limited.
- Contact submissions are validated with Zod, origin-checked, size-limited, and
  rate limited per hashed IP.
- `/admin` and `/api` are marked `noindex` and disallowed in `robots.txt`.
- Set a strong `BETTER_AUTH_SECRET`; the app refuses to start in production
  without one.

## Email

`RESEND_FROM_EMAIL` must use a domain verified in Resend. In development,
emails are logged to the console when `RESEND_API_KEY` is not set.

## Ray Academy

Courses, modules, prices, coupons and enrolments live in PostgreSQL. Run the
academy migrations above, then manage the catalogue in `db/academy.seed.sql`
and the admin area. See `docs/RAY_ACADEMY.md` for the payment flow, coupon,
instalment and webhook details, and `docs/plan-completion/BUILD-LOG.md` for the
current build status.
